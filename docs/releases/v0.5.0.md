# v0.5.0 — Unreleased

Adds an interactive terminal workbench, an optional local browser interface, and Qoder support while retaining the existing command-line migration workflow.

The default terminal interface searches and filters sessions, reads excerpts, previews migrations, and imports or exports portable files. The optional `web-ui` build provides the same core operations with source-location settings. Both use a shared Rust application layer that captures the source during preview and requires a separate write action. Listings now support search, limits and JSON; `providers` and `doctor` explain supported operations and local discovery.

Qoder CLI can be read and written natively. Its reader follows the committed branch and separates the archive from retained context. Qoder IDE hook transcripts and recent desktop histories are read-only sources. Unsupported replacement state requires explicit recovery; incomplete checkpoints fail. Desktop history without a matching native transcript does not claim to reproduce the original model context. Native Qoder 1.1.85 discovery was verified in isolated homes; authenticated continuation remains outside that verification.

The browser frontend is written in Rust using GPUI Kit 0.9.0 and compiled to WebAssembly. It uses the cobalt-and-silver artwork, with a full-width session table, project filters, an on-demand transfer inspector, role-labeled excerpts, and a history of completed transfers and exports for the browser tab. IBM Plex fonts and component icons are bundled locally. The compressed frontend is checked in with source checksums, so installing the browser feature does not require a frontend compiler. The application icon is supplied as PNG and Windows ICO. See the [interface guide](../interfaces.md) for installation and browser limitations, and [development](../development.md) for local validation. No release has been published.

Local validation covers the Rust conversion and interface tests, GPUI model tests and bundle checksums, strict Clippy, command-only and browser-only builds, browser interaction checks at desktop and narrow window sizes, the workbench API probe, and the existing 16-direction portable transfer matrix. Native Codex continuation probes use a local Responses stub; native Qoder discovery uses its official 1.1.85 CLI. These probes make no remote model requests.
