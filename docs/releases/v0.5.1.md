# v0.5.1

This patch fixes conversations that were saved in ZCode's database but missing from its Desktop sidebar, and corrects retained Qoder checkpoint replay when importing into ZCode.

## ZCode Desktop discovery

ZCode Desktop 3.17 keeps its task index separate from the CLI conversation database. Imports now register top-level conversations in that index, link them to the destination directory's unique active project, or create a project when none exists. Saved children remain attached to their parent rather than appearing as separate top-level tasks.

Registration preserves existing task preferences and rejects another host's task ownership. It shares the transcript transaction so a registration error rolls back both writes. Transfer previews also track changes to the task index and its WAL before confirmation. A custom database copy derives its index only from the selected store and never falls back to the real desktop index.

Refresh the ZCode window after importing. To update a previously hidden import, preserve any later destination turns before repeating the migration with 0.5.1. Duplicate active projects for the same directory must be resolved in ZCode before importing.

## Resume checkpoints

Bare foreign compaction markers remain in the archive without replacing ZCode's native resume boundary. This prevents retained Qoder context from failing read-back with a missing persisted summary while preserving the imported prompts, replies, reasoning and tool exchanges.

## Compatibility and validation

The portable format and provider requirements are unchanged. Local validation covers 103 Rust tests, strict Clippy, isolated workbench operations and import/export of an actual Qoder snapshot through copies of both ZCode stores. Retained conversation content was compared with the source; authenticated model continuation was not tested.

Release packaging checks checksums, archive contents, executable architecture, version and the native local interface on Windows x64, Linux x64 and macOS Apple Silicon. Both interfaces remain included in the downloads.
