### Changes

- Discover native DSH `session-UUID` folders as well as existing UUID folders. Resolve their saved names from the project cache and retain stable canonical IDs for conversion.
- Normalize prefixed DSH parent IDs so saved child sessions migrate with their parent links across mixed native and imported layouts. Accept legacy compressed `session.jsonl.zstd` transcripts too.
- Read only native session headers when finding children and cache the parent index for one conversion, avoiding repeated full-history scans for each family member.

No portable format changes are required. Upgrade to 0.3.3 when a named DSH session is missing from the list or its saved children are not discovered.
