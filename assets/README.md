# Application artwork

`icon-v2.png` is the cobalt-and-silver bridge artwork. `icon.png` is the identical browser and documentation asset; `icon.ico` packages Windows sizes from 16 to 256 pixels.

The GPUI browser module embeds static IBM Plex Sans Regular, Medium and SemiBold from [IBM Plex](https://github.com/IBM/plex), plus IBM Plex Mono from Google Fonts. The host page uses the WOFF2 Sans font while starting. Their SIL Open Font License is preserved in `fonts/OFL.txt`; all assets are local. GPUI component icons are embedded from the pinned GPUI Kit assets crate.
