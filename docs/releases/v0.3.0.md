### Changes

- Add portable session export and import for all five supported harnesses. A versioned `*.hbridge.json` file carries the normalized transcript, retained resume context, original timestamps, and optional saved child sessions to another machine. The receiving PC needs only its initialized destination harness.
- Validate the transfer format, payload checksum, and parent/child graph before writing. Export refuses to overwrite an existing file; both commands support `--dry-run`.
- Import saved subagent sessions with `--include-subagents` and translate their parent links, including nested descendants. Portable import automatically includes every child in the file and calculates destination placement on the receiving machine.
- Restore supported native compaction checkpoints instead of replaying superseded history into the model. Apply a retained-context preflight across providers, with `--resume-max-chars` and explicit `--prune-resume-context` controls; pruning preserves the complete normalized archive and protected messages/tool arguments.
- Replay imported reasoning as labeled assistant text in Codex resume context. This avoids continuing with unverifiable hidden reasoning state that can trigger `unsupported_persisted_item_context`, while retaining visible reasoning in the archive.
- Keep child-id maps outside model context and improve DSH preset-port sidebar registration, titles, and recency.

### Transfer between machines

On the source PC:

```sh
harness-bridge export "<session-id-or-title>" --from zcode --output session.hbridge.json --include-subagents
```

Copy the file to the receiving PC, initialize its destination harness, and run:

```sh
harness-bridge import session.hbridge.json --to codex --cwd "/path/to/project" --dry-run
harness-bridge import session.hbridge.json --to codex --cwd "/path/to/project"
```

Source and destination may each be `dsh`, `codex`, `claude`, `zcode`, or `agy`, including the same harness on different machines. Both PCs need version 0.3.0 or later. See `docs/portable-format.md`, included in each archive, for the format and destination requirements.

Project files and attachments must be moved separately. Paths inside transcript text remain as recorded. Reimporting can overwrite later destination turns. The checksum detects transfer damage; it does not encrypt the transcript. Saved child imports do not start agents or translate tool commands, and agy native writes remain text-only.

### Validation

All 38 local Rust tests, formatting checks, and strict all-target Clippy checks passed on Windows. An exported ZCode session imported into an isolated Codex home with the source stores unavailable; the native Codex app-server completed a tool call and continuation against a local Responses stub without unsigned reasoning in either request. This validates local replay behavior, not remote model acceptance or real Linux/macOS harness stores.
